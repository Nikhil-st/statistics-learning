Statistics Learning for Machine Learning

A practical collection of Jupyter notebooks created while learning statistical concepts and hypothesis testing for Machine Learning and Data Analysis.

📚 Topics Covered

* Hypothesis testing
* Z-test
* One-sample t-test
* Two-sample t-test
* ANOVA
* Chi-Square test
* Outlier detection and analysis
* Statistical decision-making
* Practical implementation using Python

📂 Notebooks

| Notebook                  | Topics                         |
| ------------------------- | ------------------------------ |
| `Ztest.ipynb`             | Z-test and hypothesis testing  |
| `t-test.ipynb`            | One-sample t-test              |
| `two_sample_T-test.ipynb` | Two-sample t-test              |

🛠️ Technologies

This repository documents my hands-on learning of statistics as part of my preparation for Machine Learning.

The notebooks focus on implementing statistical concepts using practical examples and understanding how hypothesis tests can be applied to data.

🧠 Key Learning Areas

Through these notebooks, I practiced:

* Formulating null and alternative hypotheses
* Understanding p-values
* Selecting appropriate statistical tests
* Interpreting test results
* Understanding significance levels
* Comparing samples and groups
* Identifying and analyzing outliers
